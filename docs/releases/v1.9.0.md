# Hearth v1.9.0

One conversation can now run a whole build. Dev Team mode puts a lead agent in
charge of a small team of engineers, and Hearth orchestrates the run: the
interview, the specification you approve, the plan, the parallel engineer
work, the milestone reviews, and the closing report.

## Dev Team mode

Start one with **New dev team** in the sidebar, or select **Dev team** on the
Home composer. The lead reads your request and the project, asks only for what
is missing, and writes a specification. You approve it (or describe a
revision), and the lead plans the build: milestones, tailored roles, and tasks
with real dependencies and path scopes.

While the team works, the conversation becomes a board. Each engineer is a
card with a name, a role, its task, and what it is doing right now; opening a
card shows its full live transcript, and any permission prompt or question an
engineer raises lands in the lane that asked. The lead reviews each completed
milestone before the next begins, and a failed task gets one round of
remediation before the truth goes into the closing handoff.

The run's own column carries the four steps, the plan and the specification,
and the run's controls: Stop parks a run without losing anything, Pause holds
new dispatch during a build, and a parked run resumes from where it stopped,
either with the Resume control or by messaging the lead. Messages sent
mid-build become durable steering notes with a visible receipt, folded into
the lead's next turn instead of interrupting an engineer mid-edit.

Everything is durable. Runs survive reloads, restarts, and provider drops;
state, spec, plan, and every engineer transcript live in plain files under
`.hearth/devteam/` in your project. Both Claude Code and the open-source Codex
CLI can drive a team, signed in as you.

See [docs/devteam.md](../devteam.md) for the full lifecycle and limits.

## Also in this release

- Agent prose renders pipe tables, and streamed text arrives at a readable
  pace instead of jumping (reduced-motion users get it whole).
- Conversations in the sidebar can be renamed or deleted from their own menu.
- Elapsed-time counters tick steadily, pad their fields, and no longer let a
  finished conversation show a working indicator.
- A stray post-turn event can no longer leave a permanent phantom "Working"
  row in a transcript.
- Wide tables in the transcript scroll and are reachable by keyboard.
