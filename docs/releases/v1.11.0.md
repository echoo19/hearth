# Hearth v1.11.0

A redesign. Hearth now shares its look with Lectern: new type, a true-dark
palette, and a lot less chrome around the conversation and the game.

## A calmer app

- One typeface carries the whole interface: Plus Jakarta Sans for every
  label, button, heading and message. Space Grotesk marks the group headings in
  the sidebar, and JetBrains Mono is kept for paths, code and the console.
- The surfaces are a warm near-black with lighter hairlines between them, so
  the running game is the brightest thing on screen.
- The current item in the sidebar, in Settings and in menus is a raised row
  rather than an orange wash. Orange is kept for the main action and live
  state.
- The uppercase labels, chips and badges are gone. A conversation's header
  shows the agent's own mark, then "Claude · Chat" or "ChatGPT · Dev team" in
  plain text. The model menu leads with the same mark.
- The composer's pickers have no borders until you point at them. Send is the
  only filled control in the row.
- What the agent did (edits, commands, reads) reads as quiet lines under its
  reply instead of a stack of grey cards. They open the same way.
- Nothing loops on its own any more. The flame moves only while an agent is
  working and goes still when it stops or is waiting on you.

## Elsewhere

- Skills drop the coloured letter tiles. A project's page splits Instructions,
  Context, the dev team and playtests with hairlines instead of boxes.
- Dev team cards share one outline, and a waiting question shows as a dot and
  a count.
- The game pane, the tester and the publish dialog lose their glows, pulses and
  frosted overlays.
