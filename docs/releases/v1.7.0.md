# Hearth v1.7.0

Conversations now survive everything short of deleting them, the model menu
tells the truth, and the terminal is the one door for agents Hearth does not
ship a driver for. A long list of small dishonesties in the interface got
fixed alongside.

## Your conversation keeps its memory

A Claude chat used to lose the agent's working memory whenever the connection
did: close the app, reopen it, and the transcript was all there but the agent
had forgotten the conversation it was in. It read like someone who remembered
nothing quoting a diary they did not recognize.

Hearth now remembers which Claude session a conversation belongs to and
resumes it. Restart the app, put the laptop to sleep, switch models mid-chat:
the agent picks up where it left off. If the old session is genuinely gone,
the chat says so plainly and continues fresh instead of dying.

## Stop means stop, not start over

Stopping a turn used to tear the whole session down. Now it ends the turn and
keeps the conversation, so stopping a wrong direction no longer costs the
agent its memory.

One more thing Stop used to do: if the agent was waiting for your permission
when the session ended, the record claimed you pressed Deny. You did not. The
record now says the question was withdrawn, which is what actually happened.

## Sign in once, pick a model any time

Hearth now runs the Claude Code you are already signed into. An API key still
works and is still supported, but it is optional. The model menu shows what
your account can actually run, switching models mid-conversation takes effect
on your next message, and Claude gets an effort dial per message for choosing
between a quick answer and a thorough one.

## The terminal is the door

Earlier versions had a protocol for registering your own agent with Hearth.
It asked agent authors to write a wrapper before their agent could do
anything. That is gone. The built-in terminal is now the way to run any agent
Hearth does not know: a real shell, opened in your project folder, with
Hearth's tools on the PATH. The game pane and the tester work the same
whoever is typing.

## The tester will not fake a session

If no agent is reachable, the tester now refuses to play and says so, instead
of running its whole session against a stand-in and writing a note that
looked real. It also stays honest about sound: muting the game now covers the
Play window too, not just the pane.

## Smaller repairs

Your project folder stays clean in git: the `.hearth` folder Hearth keeps
inside a project now ignores itself, so chats and tester notes never end up
in your commits. A project that cannot be created because the server is
unreachable says so instead of showing a spinner forever. Two projects with
the same name are told apart by where they live. The account row no longer
claims you are signed out while it is still checking. The Tester screen aims
at the project you came from. And the warning icon on the permission control
is reserved for the one mode that deserves it.
